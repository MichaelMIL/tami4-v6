HOW TO OPEN THE HIDDEN MENUS (from ui_update 0x33C8 and ui_init 0x42F6)
Key codes: 0x20 = the key that opens MAIN MENU from the home screen (MENU/OK); 0x40 = the key that backs out of menus (BACK).

SERVICE (0xE61A)
  On the running unit, hold keys 0x20 + 0x40 together. Counter ui_menu_param (0x109) counts 5 UI cycles
  (about 1-2 s), then SERVICE opens with a 60 s inactivity timeout.

INSTALLATION (0xE582): first-installation flow after SHIPPING MODE (SYSTEMCONFIG4 bit 0)
  1. Activate shipping mode: hold key 0x20 while powering on. The flag is saved in EEPROM, the LCD shows
     "SHIPPING MODE ACTIVATED", it beeps 3 times and then halts (power off).
  2. Next power-up with the flag set: heater, compressor and both thermostat tasks are stopped, the language
     list is shown, then the INSTALLATION menu (BOILING TEMP., FILL TANKS with flushing).
  3. Finishing installation ("INSTALLATION COMPLETED", 0x17A4) clears the flag and saves it.
  Skip / cancel: power on with the flag set while holding key 0x40, which shows "SHIPPING MODE CANCELLED" and clears the flag.
  Factory jumper (RB5 low at power-up) clears the flag in RAM only ("PRODUCTION MODE CANCELLED").
  NOTE: this unit's EEPROM has SYSTEMCONFIG4 = 0xE7, so bit 0 is SET. It should start in the installation flow at power-up.
