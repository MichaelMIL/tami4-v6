## Firmware v3.5.13 differences

v3.5.13 has 77 parameters (indexes 0-74 unchanged, two appended) and no serial command to read or write them (see `../v3.5.13/README.md`). ROM-table entries that differ from v3.47:

| # | Name | v3.5.13 default / range | v3.47 | Meaning |
|---|---|---|---|---|
| 3 | `TNORMALCOLDCUTOUT` | 10 °C, 5 °C … 20 °C | 10 °C, 3 °C … 20 °C | Cold-water set point (normal mode). The compressor stops when a cold sensor is at or below this, and restarts when the top sensor rises TTOPDELTACOLD above it or the bottom sensor rises TBOTTOMDELTACOLD above it. Independently, the compressor always stops at 1 °C (anti-freeze). Set from the user menu 'Cold water temp'. |
| 22 | `TDELTAHOTTOPNORMALCUTOUT` | 4 °C, 0 °C … 10 °C | 7 °C, 5 °C … 15 °C | Normal mode: top-sensor cut-out = TBOIL − this. |
| 29 | `THOTCONTALLOWDISPENSE` | 0 °C, 80 °C … 90 °C | 85 °C, 80 °C … 90 °C | Minimum top-sensor temperature for hot dispensing: hot water is enabled once the top sensor reaches this, and blocked below it in sleep mode.<br>v3.5.13 ROM default is 0, below its own minimum of 80 (as listed in the v3.5.13 README). |
| 30 | `THEATERMAXON` | 20 min, 5 min … 20 min | 9 min, 5 min … 20 min | Maximum continuous heater on-time. When it expires the heater switches off and fault 0x84 is set. The timer is reloaded while hot water is being dispensed. |

| 75 | `SYSTEMCONFIG7` | 0x02, 0x00 … 0xFF | new | New option byte in v3.5.13 (RAM mirror 0xEE0). Mostly not decoded. |
| 76 | `PLASTICSLEEPMODESTARTHEATING` | 50 °C, 45 °C … 60 °C | new | Sleep-mode heating restart temperature for a PLASTIC hot tank (new in v3.5.13). Plastic tanks use a lower sleep temperature than stainless (inferred from the name; not traced in code). |

Other v3.5.13 notes:

* `SYSTEMCONFIG2`: Language field 0x38 is what the shell command set_language=n writes (accepted n = 0-7).
* `SYSTEMCONFIG3`: v3.5.13: bit 0x02 = production mode (set_production_mode); when set, boot forces the factory configuration (SYSTEMCONFIG |= 0xBF, SYSTEMCONFIG2 = 0x40, SYSTEMCONFIG4 = 0xE7, SYSTEMCONFIG7 |= 1), as the factory jumper does.
* `SYSTEMCONFIG4`: v3.5.13: bit 0x01 is what set_shipping_mode=n writes; testing_mode=1 clears bits 0x26 in RAM.
* `SYSTEMCONFIG6`: v3.5.13: bit 0x01 is the hot tank type reported by get_hwt_type (Plastic / Stainless; RAM mirror 0xEDF). Which value means plastic is not confirmed.
