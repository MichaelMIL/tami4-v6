These switch outputs or change the operating mode. Each asks for confirmation and must be enabled under Settings (none tested on the unit yet). STOP (valves off) is always allowed.

Outputs (output=n,v)

#OutputState

Writes the port latch directly; the normal control tasks may switch it back (inferred). Testing mode probably prevents that.

Dispense (hot=a / cold=a / mix=a)

The argument is required (stored at RAM 0x10A); whether it is a volume or a time is not decoded. There is no dispense-stop command in v3.5.13: STOP switches the hot, cold and inlet valves off with output=n,0. If water still flows, use reset.

Simulate a key press (manual_press=k,t)

Key 0-6, time > 0. Key numbers and the time unit are not decoded.

Testing mode / other

Production / service settings. These write EEPROM; shipping and production mode also reset the controller. None tested on the unit yet.

Idle-screen text (settext)

Replaces the “Strauss Water” logo on the idle screen. Two rows — line 2 is optional, drawn below line 1 (shown uppercase). Needs a firmware with settext (the combined PIC18F8621-3.5.13-par-settext.hex, or the logotext.hex) and Allow EEPROM writes enabled (Settings). Empty text clears it.

Language (set_language=n)

Shipping mode (set_shipping_mode=n)

SYSTEMCONFIG4 bit 0: the first-installation flow runs at the next power-up. The controller resets afterwards.

Production mode (set_production_mode=n)

SYSTEMCONFIG3 bit 0x02. While set, every boot forces the factory configuration in RAM (SYSTEMCONFIG |= 0xBF, SYSTEMCONFIG2 = 0x40 = English, SYSTEMCONFIG4 = 0xE7), as the factory jumper does. The controller resets afterwards.
